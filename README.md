# Amey Portfolio — React

React/Vite conversion of the portfolio with real project screenshots, animated reveal effects, hover transitions and responsive layouts.

## Run

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

## Important

Three live-demo URLs were not present in the supplied HTML/history, so `src/main.jsx` leaves them clearly marked as `#` rather than inventing URLs. Replace these three values in `PROJECTS` / `MINI_PROJECTS` when you have the real deployed URLs:

- PrivateChat: `PROJECTS[0].live`
- ResumeAI: `PROJECTS[1].live`
- ClimaView: `MINI_PROJECTS[0].live`

PulseNews is already connected to `https://pulsenews-five.vercel.app/`.
